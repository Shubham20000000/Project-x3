# PC tool laboratory

General professional Business Analyst track 2.0. No prior employment, specialist system access or industry background is assumed. Fictional service-request, e-commerce and course-booking cases support practice from foundations through advanced analysis. Full-depth work is designed around 180 minutes/day. With a smaller budget, split the same lab across sessions rather than remove its acceptance checks. This is structured practice, not an automatic qualification or promise of mastery.

Start with a browser, document editor, spreadsheet and diagrams.net. Add Jira/Confluence around Day 31, SQL around Day 39, Power BI around Day 46, Postman around Day 51 and Python around Day 55. Account, OS and licence requirements vary. Alternatives must produce the same artifacts and checks.

Create Documents/BA_90_Days with Discovery, Requirements, Models, Data, Tests, Portfolio and Day_01 through Day_90 subfolders. Preserve editable files plus readable exports.

## Documents & spreadsheets

**Level:** Core. **Days:** 1–90. **Tools:** Word + Excel, or LibreOffice; Markdown is also supported.

Specifications, stakeholder/RTM/test registers, financial models, data validation and PivotTables.

**On your PC:** Create the BA_90_Days folder tree. Use Excel when practising Power Query; if unavailable, document equivalent transformations and complete the SQL/Python versions.

**Official source:** https://www.libreoffice.org/download/download-libreoffice/

## Process & system modelling

**Level:** Core. **Days:** 2–90. **Tools:** diagrams.net; Visio is an alternative.

BPMN, UML, DFD, ERD, context diagrams, decision models and architecture.

**On your PC:** Use the browser or desktop version, enable the relevant shape libraries, and save editable .drawio files plus readable exports.

**Official source:** https://www.diagrams.net/

## Backlog & knowledge workspace

**Level:** Core. **Days:** 17–90. **Tools:** Jira + Confluence; structured Excel + Markdown fallback.

Epics, stories, workflow, JQL, refinement, sprint/release planning and linked documentation.

**On your PC:** Use a personal practice workspace if available. Do not connect an employer project. A spreadsheet can reproduce the same backlog fields and states.

**Official source:** https://support.atlassian.com/jira-software-cloud/

## UX prototypes

**Level:** Core. **Days:** 12, 26–30, 76. **Tools:** Figma or Penpot.

Personas, journeys, desktop wireframes, linked prototypes, errors and usability tasks.

**On your PC:** Create a fictional portal design, save editable screens and export a PDF/PNG pack. Use a browser-based tool when installation is restricted.

**Official source:** https://penpot.app/

## SQL laboratory

**Level:** Core. **Days:** 39–90. **Tools:** DB Browser for SQLite; DBeaver/SQL Server alternatives.

Relational design, SQL, CTEs, windows, validation and reproducible analysis.

**On your PC:** Install DB Browser from its official site. Open a NEW practice database, execute practice.sql, then save queries separately. SQLite and T-SQL date syntax differ.

**Official source:** https://sqlitebrowser.org/dl/

## Business intelligence

**Level:** Core. **Days:** 46–90. **Tools:** Power BI Desktop.

Power Query, star schema, DAX, accessible reporting and decision narratives.

**On your PC:** Use Power BI Desktop on a supported Windows PC. A report publishing account is not required for local .pbix practice. If unavailable, produce Excel visuals and a written semantic/DAX design.

**Official source:** https://learn.microsoft.com/en-us/power-bi/fundamentals/desktop-get-the-desktop

## API and contract laboratory

**Level:** Core. **Days:** 50–90. **Tools:** Postman + JSON editor + Swagger Editor.

HTTP/JSON, mock requests, contracts, error handling, collections and assertions.

**On your PC:** Install Postman or use supported browser tooling. Use public echo/mock endpoints and fictional payloads. Export collections with no tokens or secrets.

**Official source:** https://learning.postman.com/docs/getting-started/installation/install-app

## Code and analytical notebooks

**Level:** Advanced practice. **Days:** 55–90. **Tools:** Python, pandas, Jupyter or VS Code.

Reproduce data checks, compare SQL results, build assertions and audit AI-assisted drafts.

**On your PC:** The bundled qa_starter.py uses only the Python standard library. pandas/Jupyter are optional extensions; create a separate local environment if you install them.

**Official source:** https://www.python.org/downloads/

## Workflow and RPA sandbox

**Level:** Advanced practice. **Days:** 68–70. **Tools:** Power Automate Desktop or local Python/CSV workflow.

Manual triggers, validation, approval simulation, outputs, audit and error handling.

**On your PC:** Use local sample files and a manual trigger. The Python alternative is a complete practice route when desktop automation or account access is unavailable.

**Official source:** https://learn.microsoft.com/en-us/power-automate/desktop-flows/install

## Versioned evidence & presentation

**Level:** Core. **Days:** 1–90. **Tools:** Git/GitHub, Markdown, PowerPoint or LibreOffice Impress, PC recorder.

File history, readable case studies, reproducible instructions and stakeholder briefings.

**On your PC:** Keep synthetic artifacts in a personal practice folder/repository. Use the PC recorder for explanations. Label all simulated projects clearly.

**Official source:** https://docs.github.com/en/get-started/start-your-journey/hello-world
